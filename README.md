# Stage LED panel - downloads

Plays websites, images and videos on a NovaStar LED screen, with a weekly schedule per item.

- **Install:** download `LedPanel_Setup_<version>.exe` from the latest release and run it (installs to C:\Stage\ledpanel).
- **Portable:** `LedPanel_<version>_portable.zip` - unzip anywhere and run `LedPanel.exe`.
- **Updates:** installed copies check this page and update themselves (`LedPanel_Update_<version>.exe`).

Needs Windows 10 (1809+) or 11 and the Microsoft Edge WebView2 Runtime (built into Windows 11).
This repository holds program downloads only - no source code.
